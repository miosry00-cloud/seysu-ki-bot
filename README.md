## ✨ Features von Seysu

* **Smarte KI-Konversation:** Reagiert direkt auf "Seysu" oder Pings und antwortet dank Google Gemini wie ein echter Charakter.
* Commands starten mit **!sey**
* **Privates Ticket-System:** Nutzer können mit `!sey ticket` einen geschützten Raum für Support-Anfragen öffnen.
* **Mini-Games & Interaktionen:** Bringt Spaß mit Befehlen wie `hug`, `slap`, `pat`, `feed`, `pout` und mehr.
* **Automatisches Willkommens-System:** Begrüßt neue Mitglieder herzlich auf dem Server und diskret per DM.
