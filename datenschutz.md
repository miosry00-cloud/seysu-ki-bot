# Datenschutzrichtlinie (Privacy Policy) für Seysu

Der Schutz deiner Daten ist uns wichtig. Dieser Bot (Seysu) speichert standardmäßig keine personenbezogenen Daten der Discord-Nutzer auf externen Servern.

1. **Datenerhebung:** Temporäre Daten wie Benutzernamen oder Server-IDs werden nur im Arbeitsspeicher des Bots verarbeitet, um Funktionen (wie das Ticket-System oder Interaktionen) auszuführen.
2. **KI-Verarbeitung:** Wenn du direkt mit der KI schreibst, werden deine Textnachrichten zur Beantwortung an die Google Gemini API weitergeleitet. Es werden keine privaten Daten dauerhaft gespeichert.
3. **Datenweitergabe:** Es werden niemals Daten an Dritte weitergegeben oder verkauft.

Bei Fragen kannst du dich direkt an den Bot-Besitzer auf Discord wenden.
